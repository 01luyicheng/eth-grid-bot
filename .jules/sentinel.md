## 2026-06-18 - Hardcoded /tmp/ Directory and Exception Swallowing
**Vulnerability:** Log files and lock files were hardcoded to the global `/tmp/` directory which allows any user to read/write, presenting a risk of symlink attacks. Furthermore, the `urllib` package was used which opens risks of processing unsafe custom protocols. Exceptions were also being silently swallowed via `try...except Exception: pass`, making debugging and incident response difficult.
**Learning:** Hardcoded paths in globally writable directories (like `/tmp`) can be maliciously linked to critical system files. `urllib.request` should be avoided for general external HTTP requests in favor of more robust libraries like `requests`. Error handling needs to be explicit, rather than silently swallowed.
**Prevention:** Use project-local, user-specific data directories (`./data`) for state and logs instead of global temp directories. Enforce the use of `requests` and validate inputs for web requests. Catch specific exceptions when possible, and ensure they are appropriately logged or re-raised to maintain visibility into failures.
